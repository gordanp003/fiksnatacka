# Auto škola Fiksna Tačka

Statički sajt spreman za GitHub Pages.

1. Otpremi sve fajlove iz ovog foldera (index.html, kategorija-*.html, kategorija.html, support.js, ft-data.js, robots.txt, sitemap.xml, favicon-*.png, apple-touch-icon.png, .nojekyll, assets/).
2. Settings → Pages → Source: "Deploy from a branch", grana `main`, folder `/ (root)`.

Sav tekst je upisan direktno u HTML (za pretraživače i AI robote); JavaScript posle učitavanja samo preuzima interakciju (meni, karusel, forma).
Adresa sajta (canonical, Open Graph, sitemap, JSON-LD) je `https://fiksnatacka.com`.
Stari linkovi `kategorija.html?k=b` automatski vode na `kategorija-b.html`.
